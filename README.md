# Health Prediction Application

## Project Overview

The Health Prediction Application is a web-based application developed using Python and Flask. It allows users to manage patient health records and generate AI-powered health remarks based on blood test results using the Google Gemini API.

## Features

* Create, Read, Update, and Delete (CRUD) patient records
* Store patient information in SQLite database
* Input validation for:

  * Email Address
  * Date of Birth
  * Blood test values
* AI-generated health remarks using Google Gemini API
* User-friendly interface built with HTML, CSS, and Bootstrap

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Bootstrap
* Google Gemini API

## Patient Information Collected

* Full Name
* Date of Birth
* Email Address
* Glucose
* Haemoglobin
* Cholesterol
* Remarks (Generated by AI)

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
cd HealthPredictionApp
```

### 2. Create a Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

### 5. Run the Application

```bash
python3 app.py
```

### 6. Open in Browser

```text
http://127.0.0.1:5001
```

## Database

The application uses SQLite for persistent storage. Patient records are stored in the `patients` table and remain available even after the application is restarted.

## AI Integration

The application integrates with the Google Gemini API. Blood test values are sent to the API, which generates health-related remarks that are automatically stored and displayed in the Remarks field.

## Validation

The application validates:

* Email format
* Date of Birth cannot be a future date
* Blood test values must be numeric
